# Fractal Identity Engine — Product Brief v0.2 (MVP)

## 0. TL;DR

Веб + мобильное приложение, которое превращает звук (микрофон или MP3/WAV) в уникальный фрактальный визуал: постер и GIF-превью.  
Пользователь: загрузил звук → уточнил музыкальный стиль → выбрал визуальный mood → покрутил 3–5 слайдеров → увидел превью с водяным знаком → при желании купил hi-res.

---

## 1. Цель продукта

Сделать **доступный, игровой, но математически честный инструмент**, который генерирует визуальный идентичный паттерн для звука: трек, голос, шум, в будущем — текст и другие сигналы.

Продуктовая цель v0.2:

> Дать любому пользователю возможность за пару минут получить красивый и уникальный фрактальный постер + GIF-превью для своего звука, а в платной версии — hi-res и историю проектов.

---

## 2. Целевая аудитория

- Любой человек, у которого есть звук: трек, голос, фон.
- Музыканты-любители, диджеи, подкастеры, стримеры.
- Люди, которым нужен «визуальный тотем» под звук:
  - обложка,
  - аватар,
  - постер,
  - превью для соцсетей.

Позиционирование v0.2: **«Игрушка для всех»** с лёгкими настройками и платным hi-res. Позже — профессиональный режим для студий и музыкантов.

---

## 3. Основной пользовательский сценарий

1. **Первый экран (simple, но не тупой)**
   - Большая кнопка: **«Загрузить звук»**.
   - Опции:
     - `Микрофон (live)` — Web Audio API.
     - `Файл (MP3/WAV)` — upload.

2. **Шаг 1 — Стиль аудио**
   - Авто-анализ на сервере (Python):
     - BPM, тональность, энергия, спектральные характеристики, продолжительность и повторяемость (через спектр/онсет паттерны) [web:47][web:50][web:52][web:55].
     - Определение длительности: sample_count / sample_rate (или готовые библиотеки: pydub, mutagen, т.п.) [web:45][web:49][web:56].
   - Интерфейс предлагает:
     - либо автоподобранный музыкальный стиль (например: «ритмичный электронный», «плавная ambient-подобная»),
     - либо выбор пользователем из нескольких жанров.

3. **Шаг 2 — Визуальный стиль**
   - Пользователь выбирает mood:
     - Mono Noir (ч/б, высокие контрасты),
     - Art/Graphica (линии, геометрия),
     - Futuristic (неон, гличи),
     - Nature (органические фракталы),
     - и т.п.
   - Это влияет на палитру, тип линий, фактуру.

4. **Шаг 3 — Фрактальные параметры (до 5 слайдеров)**
   - Панель не как у космического корабля, но так, чтобы было интересно:
     - `Complexity` — количество итераций / глубина фрактала.
     - `Symmetry` — bias симметрии (параметр c для Julia, смещение центра) [web:29][web:30][web:40][web:41].
     - `Density` — плотность элементов (сколько “структуры” на единицу площади).
     - `Noise` — уровень стохастического шума, лёгкий хаос.
     - `Motion` — интенсивность анимации для GIF (скорость изменения параметра).
   - Все значения сохраняются в `UserPreset` внутри проекта.

5. **Шаг 4 — Пуск**
   - Кнопка **«Сгенерировать превью»**.
   - Браузер (WebGL/WebGPU) рисует фрактал по переданным параметрам:
     - шейдеры Mandelbrot/Julia/IFS,
     - color mapping по визуальному стилю [web:31][web:32][web:33][web:39][web:41].

6. **Шаг 5 — Превью и действия**
   - Экран **Preview**:
     - картинка (PNG/JPG low-res),
     - короткий GIF (loop нескольких состояний, рассчитанный либо по времени композиции, либо по структуре track — например, повторяемость мотивов → повторяемость визуального паттерна).
   - На превью:
     - водяной знак,
     - несколько кнопок:
       - `Сохранить проект` (занимает один слот из 5).
       - `Экспортировать hi-res` (платно).
       - `Поделиться` (соцсети, мессенджеры).

## 4. Входные данные

### 4.1. Источники аудио

- Микрофон (live):
  - Web Audio API: stream, локальный FFT, базовые признаки (energy, спектр).
  - Можно не слать весь live на сервер для анализа, а использовать локальную оценку для визуала [web:28][web:34][web:36][web:37][web:38][web:51].

- Файлы:
  - Форматы: MP3, WAV.
  - Ограничение размера: условно до 50 МБ.
  - Длительность определяется на сервере:
    - pydub, mutagen, ffmpeg/sox и т.п. [web:44][web:45][web:49][web:56].

### 4.2. Признаки, которые считаем

Серверный анализ (Python):

- BPM (через onset envelope + autocorrelation, pyAudioAnalysis или свои методы) [web:47][web:50][web:55].
- Key / mode (хрома-профиль, Krumhansl-Schmuckler-подход) [web:37][web:38].
- Energy (интегральная мощность + динамические изменения).
- Spectral centroid / brightness (центр тяжести спектра) [web:52][web:55].
- Rhythm density (частота событий в единицу времени).
- Dynamic range (разница между тихими и громкими участками).
- Duration (общая длина трека) [web:49][web:53][web:56].
- Repetition / structure:
  - анализ повторяемости мотивов через similarity матрицы спектральных фрагментов;
  - можно использовать это для:
    - “узорности” фрактала,
    - длительности/структуры GIF-loop.

Все это складывается в `AudioAnalysis` JSON.

## 5. Выходные данные

### 5.1. Форматы

- **PNG / JPG**:
  - Постер (основной визуал).
  - Размеры:
    - стандартные (например 1080×1080),
    - hi-res (например 3000×3000) в платной версии.

- **GIF**:
  - Короткий анимированный превью:
    - 2–5 секунд,
    - зацикленный,
    - основан на медленном изменении пары параметров фрактала (zoom, rotation, c) в соответствии с музыкальными характеристиками (например, продолжительность такта, динамика) [web:57].
  - Используется как:
    - тизер для соцсетей,
    - демонстрация “живого” фрактала.

### 5.2. Хранение

- До **5 проектов** на пользователя в MVP:
  - каждый проект содержит:
    - исходный трек (или ссылку/ID),
    - `AudioAnalysis`,
    - список presets (сложность, симметрия, стили),
    - ссылки на PNG/JPG/GIF.

## 6. Архитектура: Python + Browser

### 6.1. Серверный слой (Python)

- REST API:
  - `POST /upload` — принять файл/фрагмент audio, создать `Track` + `UserProject`.
  - `POST /analyze` — построить `AudioAnalysis`.
  - `GET /project/{id}` — вернуть проект (анализ + presets + ассеты).

- Внутри:
  - Модули анализа (librosa, pyAudioAnalysis, твои скрипты) [web:47][web:50][web:52][web:55].
  - Функции получения длительности (pydub/mutagen/ffmpeg/sox) [web:45][web:49][web:56].
  - Логика формирования `RenderSeed` — минимального набора параметров, которые уйдут в браузер.

### 6.2. Клиентский слой (Browser / Mobile)

- Web Audio API:
  - захват микрофона,
  - локальный анализ для live-визуала (реактивность, не строгие метрики) [web:28][web:36][web:37][web:38][web:51].

- WebGL / WebGPU:
  - шейдеры для Mandelbrot, Julia, IFS, и других фракталов [web:29][web:31][web:32][web:33][web:39][web:40][web:41].
  - Canvas → экспорт в PNG/JPG.
  - Offscreen рендер для генерации GIF.

- Mobile:
  - Нативное приложение (iOS/Android) как оболочка над:
    - WebView с тем же интерфейсом,
    - плюс нативный доступ к микрофону,
    - плюс локальное хранение мини-ассетов.

## 7. Монетизация

### 7.1. Бесплатная версия

- 2–3 бесплатные генерации в день / месяц (конфигурируемо).
- До 5 проектов.
- Экспорт в стандартном разрешении:
  - PNG/JPG с небольшим watermark.
  - GIF-превью с watermark.

### 7.2. Платная версия

- Hi-res экспорт (постеры под печать, большие размеры).
- Больше проектов.
- Отсутствие watermark.
- Расширенный набор визуальных стилей.
- В будущем:
  - “Pro mode” для студий:
    - batch-обработка,
    - кастомные стили,
    - брендированные пресеты.

## 8. Далее по дорожке развития

В будущем (после MVP):

- **Текст на вход**:
  - стихи, фразы, любой текст;
  - превращение семантики в параметры фрактала (идея зафиксирована, как отдельный модуль).
- **Психологический тест / нелинейные преобразования**:
  - источники данных:
    - голос,
    - паттерны поведения,
    - физиология и т.д.
  - визуал как “форма состояния” или “прогноз исходов”.
- **Pro-режим для музыкантов/студий**:
  - более тонкие настройки,
  - серийная генерация,
  - интеграция с DAW.

---

## 9. Критерий успеха MVP v0.2

> Пользователь без ручного чтения документации заходит, за 3–5 минут:
> 1. Грузит звук (микрофон или файл),
> 2. Уточняет музыкальный и визуальный стиль,
> 3. Крутит до 5 понятных слайдеров,
> 4. Получает превью с водяным знаком,
> 5. Может сохранить проект и, при желании, купить hi-res.

Если это работает стабильно и выглядит достаточно «вау», чтобы пользователь захотел поделиться этим фракталом — первый блин не комом, а фракталом.
