## 2. Что собрано

### 2.1 Словарь отдельных цветов — 159/159 (100%)
Источник: `wadacolors.com/colors/`
Для каждого цвета зафиксированы: английское название, HEX. Полный набор RGB/HSB/CMYK/LAB подтверждён форматом на образце:

| Цвет | HEX | RGB | HSB | CMYK | LAB |
|---|---|---|---|---|---|
| English Red | #D86310 | 216,99,16 | 25°,93%,85% | 13%,73%,100%,0% | 55.6%, 42.2, 61.1 |
| Yellow | #FFF100 | 255,241,0 | 57°,100%,100% | 0%,0%,100%,0% | 93.5%, -14.8, 91.9 |
| Black | #191110 | 25,17,16 | 7°,36%,10% | 20%,10%,15%,100% | 5.8%, 3.4, 1.8 |

(полный список 159 цветов собран и доступен для выгрузки по запросу)

### 2.2 Реестр комбинаций — 348/348 (100%)

| Тип палитры | Диапазон номеров | Количество |
|---|---|---|
| 2-цветные | #001–#120 | 120 |
| 3-цветные | #121–#240 | 120 |
| 4-цветные | #241–#348 | 108 |
| **Итого** | | **348** |

Для каждой из 348 комбинаций собраны названия входящих в неё цветов (полностью, по всем 348 номерам). Примеры:
- #001: English Red, Cerulian Blue
- #159: Khaki, Calamine Blue, Grayish Lavender - A
- #241: Red Orange, Pale Lemon Yellow, Isabella Color, Dark Medici Blue

### 2.3 HEX для комбинаций
Точные HEX подтверждены выборочно (~60 комбинаций с главной страницы + отдельные образцы). Для остальных HEX восстанавливается автоматическим join по имени цвета с полным словарём 159 цветов (п. 2.1) — начисление точных HEX/RGB/LAB для всех 348×N цветовых полей не требует дополнительного браузинга.
