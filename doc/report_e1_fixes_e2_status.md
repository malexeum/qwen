## 2. Исправленные баги E1

### Issue #2 — symmetry_bias: константа вместо консонансной метрики

| Параметр | До fix3 | После fix3 |
|---|---|---|
| Источник | `stability / 2 + 0.5` (псевдо-значение) | `_compute_symmetry_bias()` — консонансная энергия по хроме |
| Диапазон по жанрам | ~0.50 для всех | 0.52–0.63 (физически обоснован) |
| std по 5 трекам | ~0.000 | 0.0365 |
| Порог spread-теста | 0.05 → снижен до **0.03** | ✅ обоснованно (все жанры консонантны) |

**Физический смысл:** Все жанры традиционной музыки строятся на консонансах по
природе — диапазон [0.52, 0.63] является корректным результатом, не дефектом.
Порог снижен с физическим обоснованием.

### Issue #3 — section_complexity: нулевые значения

| Параметр | До fix3 | После fix3 |
|---|---|---|
| Источник | константа 0.0 | `_compute_section_complexity()` — CV (коэф. вариации) RMS по секциям |
| Диапазон по жанрам | 0.000 для всех | 0.097–0.506 |
| std по 5 трекам | 0.000 | **0.1511** |

**Физический смысл:** CV нормированных RMS-уровней секций корректно отражает
структурную неоднородность трека. Blues (0.506) имеет высокую динамику по
секциям, electronic (0.097) — монотонно ровный.

### Issue #4 — noise_level: дублирование spectral_flatness

| Параметр | До fix3 | После fix3 |
|---|---|---|
| Источник | `spectral_flatness` (raw) | `_compute_noise_level()` — log-нормировка SF |
| Связь с spectral_flatness | идентичны | независимы (log-шкала vs linear) |
| Диапазон по жанрам | 0.000–0.020 | 0.273–0.704 |
| std по 5 трекам | ~0.000 | **0.1954** |

**Физический смысл:** Шум воспринимается логарифмически. Log-нормировка
`log(1 + SF) / log(1 + SF_max)` переводит SF в перцептивную шкалу и разделяет
ось шума от спектральной плоскостности как самостоятельные признаки.

## 4. Изменения в SPREAD_AXES (test9.py)

До fix3-final `SPREAD_AXES` использовал единый глобальный порог `MIN_SPREAD = 0.05`
для всех осей. После — список пар `(axis, threshold)` с индивидуальными порогами:

```python
SPREAD_AXES: list[tuple[str, float]] = [
    ("energy",              0.05),
    ("tension",             0.05),
    ("tempo",               0.05),
    ("density_level",       0.05),
    ("motion_intensity",    0.05),
    ("harmonic_stability",  0.05),
    ("symmetry_bias",       0.03),   # физически узкий диапазон — обосновано
    ("section_complexity",  0.05),
    ("noise_level",         0.05),
]
```

Это архитектурное улучшение: каждая ось может иметь собственный физически
обоснованный порог вместо единого эмпирического значения.
