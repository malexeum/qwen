## 4. Что было реализовано в E3

### 4.1 RenderParams — 8 новых theta-полей

```python
harmony_theta_0 .. harmony_theta_7  # float ∈ [0.0, 1.0], default 0.5
```

Каждая ось независима. Нейтральное значение — 0.5. Все 8 осей входят в `theta_hash` — детерминированный hex-ключ 16 символов для воспроизводимости сида генератора.

### 4.2 resolve_render_params — declarative pipeline

Четыре слоя (stage):
1. **Base layer** — из `StyleProfile` (YAML)
2. **Perceptual layer** — из `InterpretationProfile.mapping_rules`
3. **User layer** — из `UserPreset` (слайдеры)
4. **Guardrails** — из `InterpretationProfile.guardrails` (clamp)

Каждое изменение параметра логируется в `MappingTrace` (param, source, raw, final, stage).

### 4.3 Новые canonical style-профили

| Slug | Палитра | Характер |
|---|---|---|
| `rock` | `dark_saturated` | Высокая энергия, угловатость, органика |

## 5. Что было исправлено в E3-C (Corrective Pass)

### 5.1 noise_proxy — физически независимый прокси

**Было (до E3-C):** `noise_level` вычислялся с включением `tension` и `density` — ложная причинность.

**Стало:**
```python
# noise_proxy ← _log_normalize(spectral_flatness)
# или явный perceptual['noise_proxy'] (приоритет)
noise_level = base + (noise_proxy - 0.5) * 0.30 + (harmony_theta_5 - 0.5) * 0.25
```

`density` полностью исключён из формулы `noise_level`.

### 5.2 _log_normalize

```python
def _log_normalize(x: float, scale_max: float = 1.0) -> float:
    # x < 0 → 0; x > scale_max → 1.0 (clamp); log1p-масштабирование, монотонное
```

### 5.3 Запрет dangling alias

`_normalize_style_slug` бросает `ValidationError` при dangling alias. `jazz → blues_jazz` удалён: `jazz` стал canonical.

### 5.4 Palette derivation пороги

`brightness > 0.60 → bright-variant`, `< 0.30 → dark-variant`, `[0.30, 0.60] → base`. Пороги строгие (не включают). None/empty → fallback.

### 5.5 _compute_morphology_guard

```
guard = clamp(base
  + (section_complexity - 0.5) * 0.40
  + (tension - 0.5) * 0.30
  - (repetition - 0.5) * 0.25
  - (stability - 0.5) * 0.20
, 0.0, 1.0)
```
