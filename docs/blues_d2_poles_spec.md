# D2 Blues: два типа постера, параметры, источники, границы (v8.1)

Статус: контракт перед реализацией BluesCompositionGrammarV8.

## 0. Цель и правила

Цель: генератор визуальной личности блюза, где вся геометрия причинно выводится по цепочке Audio → E1 → E2 θ → BluesBridgeParams → SVG и записывается в MappingTrace.

Правила:
- Один трек → одна картина. Альтернативных картинок не плодим.
- Тип постера выбирается один раз на трек и внутри трека не переключается.
- Вариативность идёт только внутри числовых коридоров из разделов 4–7.
- Любой параметр без измеренного источника помечается `derived_estimate`.

## 1. Два типа постера

| Тип | `blues_poster_type` | Смысл | Сцена |
|---|---|---|---|
| S | `solitude` | Одиночество: одно тело оседает к земле | Тело-чаша, тень на поверхности, roots/rails, нижний узел, спектральные круги, funnel. Нет второго тела, нет моста, нет inter-body field |
| D | `dialogue` | Взаимодействие двух тел: Голос и Тело | Голос (цветок-воронка), Тело (резонаторная чаша), мост call-and-response, contact_seam, inter-body field |

Холст 1080×1080, нижняя плашка паспорта 180 px. Рабочая область сцены: 1080×900 (y от 0 до 900).

## 2. Выбор типа (аналог dominant_mode в роке)

В роке `dominant_mode` ("structure" или "organic") выбирает гнездо или бутон по отношению θ1 (стабильность формы) к θ7 (кристалличность). Для блюза тип выбирается по мягкому счёту взаимодействия.

\[ dialogue\_score = 0.30\,\theta_4 + 0.25\,\theta_2 + 0.20\,repetition + 0.15\,onset\_rate\_norm + 0.10\,G \]

| Условие | Тип |
|---|---|
| dialogue_score ≥ 0.55 | `dialogue` |
| dialogue_score ≤ 0.45 | `solitude` |
| 0.45 < score < 0.55 | `solitude` (нейтральный, меньше элементов) |

Пороги 0.45 и 0.55 предварительные. Их нужно откалибровать на корпусе блюзовых треков до заморозки.

Физико-музыкальный смысл: плотные, контрастные по частям, повторяющиеся треки с частыми атаками (переклички, ответы инструмента вокалу) дают диалог. Разреженные, ровные, медленные треки с одним несущим голосом дают одиночество.

Счёт записывается в MappingTrace со всеми входами, весами и итоговым типом.

## 3. Таблица управления (аналог таблицы рока)

| Визуальный элемент | Управляющий параметр | Музыкальный источник | Физико-музыкальный смысл |
|---|---|---|---|
| Тип постера | `blues_poster_type` | θ4, θ2, repetition, onset_rate, G | Одиночество или диалог (раздел 2) |

| Слайдовая деформация лент | `Abend = 8 + 28·θ3` | θ3 (неразрешённое напряжение) | Блюзовая нота и бенд: напряжение изгибает ленты |
| Длина волны деформации | `λbend = 100 + 180·(1 − drive)` | drive | Резкий драйв даёт короткие складки, мягкое звучание даёт плавные |
| Число лент в чаше | `ribbons = 3 … 7` по G | G | Плотность и повторяемость грува |

| Длина лепестков | `Lk = L0·[1 + 0.22·V·sin φk + 0.18·E·cos(2φk + θ3)]` | V, E, θ3 | Яркость голоса и электрический жар |
| Изгиб моста (тип D) | `As = 25 + 70·θ3` | θ3 | Амплитуда blue note в перекличке |
| Сдвиг ответа (тип D) | `δswing = 0.12π + 0.18π·repetition·(1 − stability)` | repetition, stability | Шаффл и запаздывание ответа |
| Толщина моста | растёт с E | E (electric_heat) | Электрический жар |
| Хвост моста | растёт при низком BPM | BPM | Тянущееся эхо в медленном темпе |
| Искры и графитовая пыль | плотность по E, не более одного акцента | E, noise_proxy | Шум, ламповый гул, электричество |
| Индивидуальный seed | `seed_sha256` | `sha256(canonical_theta_hash + feature_sha256)` | Воспроизводимость, внешней случайности нет |

## 4. Производные оси

Все входы нормируются в [0, 1] и ограничиваются clamp. BPM в формулах ограничивается диапазоном 55 … 145.

| Ось | Формула | Диапазон |
|---|---|---|
| tempoNorm | clamp((BPM − 55) / 90, 0, 1) | [0, 1] |
| G groove_weight | 0.30·density + 0.25·repetition + 0.20·energy + 0.15·stability + 0.10·tempoNorm | [0, 1] |
| V vocal_presence | 0.30·brightness + 0.25·θ0 + 0.20·smoothness + 0.15·stability + 0.10·(1 − noise_proxy) | [0, 1] |
| E electric_heat | 0.30·drive + 0.25·noise_proxy + 0.20·θ3 + 0.15·θ5 + 0.10·θ4 | [0, 1] |

Честность данных: эти оси пока производные оценки. Четыре признака (swing_ratio, vocal_presence, low_end_ratio, bend_vibrato_rate) в E1 не измеряются. Пока их нет, значение берётся из fallback-формул выше и помечается в MappingTrace как `derived_estimate`.

## 5. Положение тел (холст 1080 по X)

### Тип D (диалог)

| Параметр | Формула | Границы при G, V, E ∈ [0, 1] |
|---|---|---|
| xA (Голос) | 540 − 120·G + 55·V | 420 … 595 |
| yA | 360 − 70·V − 35·E | 255 … 360 |
| xB (Тело) | 540 + 120·G − 45·V | 495 … 660 |
| yB | 680 + 110·G + 45·E | 680 … 835 |

Инварианты:
- Вертикальное расстояние yB − yA ≥ 320 px (минимум достигается при G = V = E = 0). Иначе диалога нет.
- yB + радиус чаши ≤ 900 (верх плашки паспорта). При yB = 835 радиус чаши не должен превышать 65 px. Реальный радиус надо проверить по коду.
- Голос выше и левее центра масс, Тело ниже и правее.

### Тип S (одиночество)

- Одно тело: x = 540, y = yB по той же формуле (680 … 835). Предложение, требует подтверждения.
- Голоса, моста и inter-body field нет.
- Верхняя часть кадра отдаётся пустоте и тени, это часть смысла.

## 6. Тело: резонаторная чаша (оба типа)

- Катеноид: y(x) = y0 + a·[cosh((x − x0)/a) − 1].
- Практический диапазон a ≈ 110 … 268.
- Слайдовая деформация: y'(x) = y(x) + Abend·sin(2πx/λbend + ψ), где Abend = 8 … 36 px, λbend = 100 … 280 px.
- Лент в чаше от 3 до 7 (по G).
- Roots слегка ослаблены, нижний узел усилен локально.
- Тип S добавляет тень на поверхности и спектральные круги нижнего плана. Тип D их ослабляет, чтобы не конкурировать с мостом.

## 7. Голос и мост (только тип D)

### Голос

- N лепестков: 3 при V < 0.35; 5 при 0.35 ≤ V < 0.65; 7 при V ≥ 0.65.
- Максимальное смещение углов |ε| ≈ 0.09 рад.
- Длина лепестка в коридоре 0.6·L0 … 1.4·L0.
- Opacity лепестков 0.35 … 0.65.
- 12-лепестковая симметрия запрещена.

### Мост

Мост B(t) строится как кубическая кривая Безье от PA к PB, где PA и PB берутся из `seam_pts`.

- C1 = PA + 0.33·(PB − PA) + As·(sin ψ, cos ψ)
- C2 = PA + 0.66·(PB − PA) − As·(sin(ψ + δswing), cos(ψ + δswing))
- As = 25 … 95 px; δswing = 0.12π … 0.30π.

Роли тел и моста:
- Мост и inter-body field строятся только от `seam_pts` и притяжения/отталкивания. Тела не рисуют собственных полей.
- Прямая линия Голос–Тело запрещена.
- `_counterflow` удаляется из кода целиком (определение, вызовы, параметры), а не скрывается флагом. Проверка: поиск по `_counterflow` в `tools/render_d2_blues_poster.py` возвращает пустой результат.

## 8. Стилистические режимы внутри типа

Режим сдвигает параметры только внутри коридоров разделов 5–7. Выбор: argmax мягкого счёта, при разнице с вторым местом меньше 0.05 берётся нейтральный режим.

| Режим | Основные признаки | Допустим в типе | Эффект |
|---|---|---|---|
| slow_delta | BPM низкий, smoothness высокий, drive низкий | S, D | Очень глубокая чаша, тонкий длинный мост |
| vocal_soul | V, brightness, stability высокие | D | Яркая воронка с нимбом, мягкий резонатор |
| shuffle | repetition и onset_rate высокие, средний BPM | D | Компактная розетка, серия коротких смещённых линий |
| electric_chicago | E, grain, density высокие | S, D | Плотное низкое тело, толстый мост, искры, дым |
| guitar_texas | атака и section_complexity высокие | D | Острые лепестки-слайды, прерывистые траектории |

Пороги счёта режимов не заморожены и калибруются на корпусе.

## 9. Палитра warm_midnight

Источник: `configs/palettes.yaml`, палитра `warm_midnight`, семейство `warm_dark`.

| Роль | Значение |
|---|---|
| Фон (RGBA) | 14, 9, 5, 255 |
| Градиент, позиция 0.00 | #0E0905 |
| Градиент, позиция 0.35 | #3D2210 |
| Градиент, позиция 0.68 | #8B4F1A |
| Градиент, позиция 1.00 | #D4923A |
| Акцент | #F5C97A |
| saturation_budget | 0.62 |
| contrast | 1.12 |
| luminance_gamma | 0.96 |

Принципы:
- Один акцент на план (`max_accents_per_plan: 1`). Искры и графитовая пыль не вводят второй акцент.
- Голос и Тело берут цвета из одного градиента: Голос из верхней части (#8B4F1A … #D4923A), Тело из нижней (#3D2210 … #8B4F1A).
- Синий электрический край в палитре отсутствует. Если он нужен при E > 0.6, его надо добавить в реестр палитр под отдельным slug, иначе валидация отклонит неизвестный цвет. Решение пока не принято.

## 10. Паспорт и воспроизводимость

- seed = sha256(canonical_theta_hash + feature_sha256), внешней случайности нет.
- В MappingTrace для каждого параметра пишутся: имя, формула, входы, источник (`measured` или `derived_estimate`), итоговое значение, применённый clamp.
- Плашка паспорта 1080×180, цвет #14100E, название прописными, hash моноширинным шрифтом.

## 11. Критерии готовности

1. Все параметры из разделов 2–7 имеют записи в MappingTrace.
2. `_counterflow` отсутствует в коде.
3. Тип постера выбирается один раз на трек и записан в трейс.
4. Для эталонных треков каждого типа различимы глазами (минимум по одному на S и D, по одному на каждый режим).
5. Один и тот же трек даёт побитово идентичный SVG.
6. Инварианты раздела 5 выполняются на всём корпусе.
