# Анатомия и семантика Rock-постера D1: руководство по интерпретации визуала в музыку

## 1. Концептуальный манифест
Rock-постер в системе AVCoder — это не декоративная абстракция и не эквалайзер. Это **причинный визуальный отпечаток (causal visual identity)** произведения, построенный на законах органической синестезии, сакральной геометрии и динамических систем.

Музыкальная драматургия рока объединяет жесткий риффовый каркас, пульсирующую энергию ритм-секции, гармоническое напряжение диссонансов, аналоговую фактуру гитарного перегруза и атмосферный вихревой континуум.

Цепочка преобразования:
Audio (E1 Features) -> Harmony θ (E2 Vector) -> BridgeParams -> Geometry & Dynamic Systems -> SVG / PNG + Provenance

## 3. Математические модели и формулы

### 3.1. Вихревые поля «Солярис» и равновесные аттракторы Ляпунова
Фоновые океанические слои («Солярис») моделируют фазовое пространство реверберации и гармонической инерции. Линии тока генерируются квазиустойчивым вихревым полем:
dx/dt = -λ * y + ω * x * (1 - (x² + y²) / R_max²)
dy/dt =  λ * x + ω * y * (1 - (x² + y²) / R_max²)

Где:
- Показатель устойчивости Ляпунова λ определяется музыкальной стабильностью: λ = 0.5 + 0.5 * stability. При λ > 0 система стремится к предельному циклу (устойчивый океан); при падении stability траектории расходятся в турбулентный рок-хаос.
- Угловая частота вихря ω = drive * π * θ₆ (энтропия развития).
- Равновесный радиус предельного цикла R_max = 240 + 180 * resonance.
- Контуры слоев Соляриса отрисовываются набором сопряженных сплайнов Безье с градиентами низкой оптической плотности (opacity ∈ [0.03, 0.08]).

### 3.2. Периферийное гравитационное линзирование (`_theta_arcs`)
Дуги формируются как фрагменты деформированных орбит:
r(φ) = r_base * (1.0 + 0.07 * sin(2φ + tension) + 0.03 * cos(3φ))
x(φ) = fx + r(φ) * cos(φ)
y(φ) = fy + 0.86 * r(φ) * sin(φ)

Функция растворения в темноте (Soft Edge Fading):
alpha(t) = base_op * sin²(π * t),  t ∈ [0, 1]

Квадрат синуса обеспечивает плавное появление дуги из пустоты, кульминацию в центре и мягкое исчезновение краев.

### 3.3. Сакральная геометрия розетки (`_sacred_flower_geometry`)
Каждый лепесток образуется пересечением двух окружностей радиуса R со смещенными центрами:
(x - x₁)² + (y - y₁)² = R²  ∩  (x - x₂)² + (y - y₂)² = R²

В SVG реализуется парой дуг:
path = "M x0 y0 A R R 0 0 1 x1 y1 A R R 0 0 1 x0 y0"
Коэффициент прозрачности слоя: opacity = 0.35 + 0.30 * θ₇.

### 3.4. Гравитационный дриппинг и микрокапли (`_bold_dripping`)
Стекающие струи туши моделируются квадратичными кривыми Безье:
B(t) = (1 - t)² * P₀ + 2(1 - t)t * P_ctrl + t² * P_end
где:
- P₀ = (x₀, y₀) — точка отрыва на лепестке или узле;
- P_ctrl = (x₀ + δ_wind, y₀ + 0.5 * L);
- P_end = (x₀ + Δx, y₀ + L),  L = uniform(50, 170) + 80 * drive.

Форма капель — эллипсы, вытянутые гравитацией:
ry = rx * k_stretch,  k_stretch ∈ [1.3, 2.2]

### 3.5. Текстурный шум полотна (`_paper_canvas_texture`)
Фактура строится процедурно:
- 160 волокон бумаги: длина l ∈ [2.5, 7.0] px, угол θ ∈ [0, π], opacity ∈ [0.04, 0.12].
- 350 микропор: радиус r ∈ [0.4, 0.9] px, opacity ∈ [0.05, 0.16].
### 3.6. Акустическая динамика: BPM, спектральный баланс и динамический диапазон

Три дополнительные оси связывают глобальное поведение музыкального полотна с геометрией:

1. **BPM (Темп ритм-секции) -> Волновой шаг и длина стебля:**
   Темп определяет частоту пульсации басового ствола:
   k_wave = (bpm / 120.0)
   len_stem = (390.0 + 150.0 * drive) * (0.85 + 0.15 * min(1.5, max(0.65, k_wave)))
   В треках с высоким темпом стебель получает более упругий, частый шаг волны; в медленных композициях — удлиненную, пластичную дугу.

2. **Spectral Skewness (Спектральный перекос) -> Гравитационный сдвиг центра массы:**
   Баланс высоких и низких частот смещает вертикальную координату фокуса цветка (cy):
   Δy = (spectral_skewness - 0.5) * 30.0 px
   cy_effective = cy_base + Δy
   Низкочастотный, тяжелый рифф оттягивает цветок вниз (к земле под действием гравитации массы); трек с преобладанием верхов и тарелок приподнимает его в верхние слои.

3. **Dynamic Range (Динамический диапазон / Компрессия) -> Дисперсия ореола ядра:**
   Амплитудное «дыхание» трека определяет мягкость границы фильтра свечения:
   stdDeviation_glow = 8.0 + 10.0 * dynamic_range
   Сжатый, плотный мастер (малый диапазон) дает сфокусированное, жесткое ядро; трек с выраженными перепадами громкости создает рассеянный, глубоко тающий в темноте ореол.
