# натомия и семантика Rock-постера D1: руководство по интерпретации музыки в визуальный образ

## 1. онцепция и назначение
Rock-постер D1 — это детерминированный визуальный паспорт музыкального произведения в жанровой вселенной Rock. го цель — не нарисовать случайную иллюстрацию, а перевести объективные свойства аудиосигнала (энергию, плотность, тембр, гармоническое напряжение) в строгую причинную геометрию.

аждый элемент на постере имеет формульное обоснование и однозначный акустический смысл:

```text
Audio Features (E1) -> Harmony Vector θ (E2) -> BridgeParams -> Geometric Layers -> SVG / PNG + Provenance
```

## 2. арта соответствия: визуал <-> музыка

| Слой визуала | узыкальный эквивалент | Управляющие параметры | оведение и формулы |
|---|---|---|---|
| **Центральное золотое ядро (Core Glow)** | Тональный центр / елодическое ядро композиции | `energy`, `brightness`, θ₀ (гармоническая чистота) | адиальный градиент `#FEF3C7` -> `#F6C85F` -> `#EA580C`. адиус `r = 18 + energy * 16`. ри росте энергии ядро расширяется и усиливает свечение. |
| **иафрагма ядра (Iris Mechanism)** | Степень гитарного перегруза / овердрайв | `drive`, `tension`, θ₃ (напряжение) | еханический затвор из перекрывающихся лепестков. Угол раскрытия сегментов уменьшается при росте напряжения: `gap = 1.0 - tension * 0.45`. |
| **Сакральный цветок (Sacred Lotus)** | армоническая структура / Смена аккордов | `stability`, `density`, θ₁, θ₂ | 12-лепестковая розетка сакральной геометрии. нутренний ярус пурпурный (`#C75CEB`), внешний янтарь (`#F6C85F`). ерекрытие дуг `R = 65..120px` задает полифоническую глубину. |
| **стрые ланцетовидные лепестки** | иффовая атака / Удары медиатора / Транзиенты | `drive`, `section_complexity`, θ₄ (контраст) | нешний венец стреловидных лепестков. аострение верхушек растет пропорционально `drive`, создавая ощущение рокового драйва и колючести. |
| **рганический стебель и побеги (Stem & Vines)** | асовая линия / ульсация суб-гармоник | `stability`, `tempo_bpm`, θ₂ | убические кривые езье, стекающие вертикально вниз под действием музыкальной гравитации. згибы `dx ~ sin(y * freq + tension)`. |
| **Светящиеся узлы (Spore Nodes)** | Синкопы / кценты ритм-секции / нсеты | `onset_rate`, `repetition` | олотистые сферы на концах побегов с диффузным ореолом рассеяния `stdDeviation=4`. тмечают метрическую сетку трека. |
| **ериферийные дуги (Einstein Rings)** | еверберация / ространственный сустейн / хо | `resonance`, `smoothness`, θ₆ (энтропия) | Широкие орбитальные дуги на периферии (`r = 330..520px`). атухание краев по закону `alpha(t) = base_alpha * sin²(π*t)`, большая часть дуги тает в пустоте. |
| **равитационный дриппинг (Ink Dripping)** | кустическая масса / лотность звуковой волны | `grain`, `drive`, `tension` | ертикальные струйки туши с каплями на концах. апли вытянуты гравитацией: `ry = rx * (1.3..2.2)`. лотность зависит от `grain` и `drive`. |
| **Фактура офортной бумаги (Paper Canvas)** | Тембральный шум / налоговый ламповый воздух | `noise_proxy`, θ₅ (тембральный хаос) | нсамбль из 160 микроволокон и 350 микропор бумаги. Убирает цифровой векторный блеск, придавая эффект шелкографии на хлопковом листе. |
| **лубокий фон (Cosmic Void)** | инамический диапазон / ауза перед кульминацией | онтраст секций | архатный глубокий цвет `#0E131F` / `#0A0D14`. Создает бесконечную глубину для люминесцентных слоев. |

## 3. атематические модели слоев

### 3.1. ериферийное линзирование (`_theta_arcs`)
рбиты дуг рассчитываются в полярных координатах со смещением центра `(fx, fy)`:
```text
r(φ) = r_base * (1.0 + 0.07 * sin(2φ + tension) + 0.03 * cos(3φ))
x(φ) = fx + r(φ) * cos(φ)
y(φ) = fy + 0.86 * r(φ) * sin(φ)
```
атухание прозрачности вдоль параметра пути `t ∈ [0, 1]`:
```text
alpha(t) = base_op * (sin(π * t))²
```
вадрат синуса гарантирует быстрое падение на краях и чистое растворение дуги в черном фоне.

### 3.2. Сакральная розетка цветка (`_sacred_flower_geometry`)
онтур лепестка строится пересечением двух сопряженных дуг окружностей радиуса `R`:
```text
d = "M x0 y0 A R R 0 0 1 x1 y1 A R R 0 0 1 x0 y0"
```
Угол поворота каждого лепестка `k` из `N`:
```text
θ_k = k * (2π / N) + phase_offset
```
нутренний ярус (N=12) повернут относительно внешнего (N=12) на `π/12` радиан, формируя эффект калейдоскопической интерференции.

### 3.3. равитационный дриппинг (`_bold_dripping`)
Траектория струи туши моделируется квадратичной кривой езье с вектором падения:
```text
P(t) = (1-t)² * P_start + 2(1-t)t * P_ctrl + t² * P_end
P_ctrl = (x_start + δ_wind, y_start + 0.5 * L)
P_end  = (x_start + Δx, y_start + L)
```
где длина струи `L = uniform(50, 170) + 80 * drive`.
Форма капли на конце струи — эллипс с вертикальным удлинением `ry / rx ∈ [1.3, 2.2]`.

### 3.4. Текстура хлопкового листа (`_paper_canvas_texture`)
Фактура синтезируется процедурно без использования тяжелых растровых фильтров:
- 160 волокон: отрезки длиной `2.5..7.0 px` со случайным углом наклона и низкой прозрачностью `0.04..0.12`.
- 350 микропор: точки радиусом `0.4..0.9 px` с прозрачностью `0.05..0.16`.

## 4. аспортный блок и типографика
ижняя плашка постера (`1080 × 180 px`, цвет `#14100E`) оформлена по швейцарской сетке:
- **Title (`.title`):** азвание аудиофайла в верхнем регистре, полужирный гротеск, трекинг `4px`, цвет `#E9EEF8`.
- **Identity Hash (`.hash`):** Строка вида `<profile> · seed <hex>`, моноширинный шрифт `Consolas`, трекинг `2px`, цвет `#7D8798`.
