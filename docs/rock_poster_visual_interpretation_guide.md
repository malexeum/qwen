# натомия и семантика Rock-постера D1: руководство по интерпретации музыки в визуальный образ

## 1. онцептуальный манифест
Rock-постер в системе AVCoder — это не декоративная абстракция и не эквалайзер. то **причинный визуальный отпечаток (causal visual identity)** произведения, построенный на законах органической синестезии, сакральной геометрии и динамических систем.

узыкальная драматургия рока объединяет жесткий риффовый каркас, пульсирующую энергию ритм-секции, гармоническое напряжение диссонансов, аналоговую фактуру гитарного перегруза и атмосферный вихревой континуум.

Цепочка преобразования:
Audio (E1 Features) -> Harmony θ (E2 Vector) -> BridgeParams -> Geometry & Dynamic Systems -> SVG / PNG + Provenance

## 3. атематические модели и формулы

### 3.1. ихревые поля «Солярис» и равновесные аттракторы япунова
Фоновые океанические слои («Солярис») моделируют фазовое пространство реверберации и гармонической инерции. инии тока генерируются квазиустойчивым вихревым полем:
dx/dt = -λ * y + ω * x * (1 - (x² + y²) / R_max²)
dy/dt =  λ * x + ω * y * (1 - (x² + y²) / R_max²)

де:
- оказатель устойчивости япунова λ определяется музыкальной стабильностью: λ = 0.5 + 0.5 * stability. ри λ > 0 система стремится к предельному циклу (устойчивый эмбиентный океан); при падении stability траектории расходятся в турбулентный рок-хаос.
- Угловая частота вихря ω = drive * π * θ₆ (энтропия развития).
- авновесный радиус предельного цикла R_max = 240 + 180 * resonance.
- онтуры слоев Соляриса отрисовываются набором сопряженных сплайнов езье с градиентами низкой оптической плотности (opacity ∈ [0.03, 0.08]).

### 3.2. ериферийное гравитационное линзирование (`_theta_arcs`)
уги формируются как фрагменты деформированных орбит:
r(φ) = r_base * (1.0 + 0.07 * sin(2φ + tension) + 0.03 * cos(3φ))
x(φ) = fx + r(φ) * cos(φ)
y(φ) = fy + 0.86 * r(φ) * sin(φ)

Функция растворения в темноте (Soft Edge Fading):
alpha(t) = base_op * sin²(π * t),  t ∈ [0, 1]

вадрат синуса обеспечивает плавное появление дуги из пустоты, кульминацию в центре и мягкое исчезновение краев.

### 3.3. Сакральная геометрия розетки (`_sacred_flower_geometry`)
аждый лепесток образуется пересечением двух окружностей радиуса R со смещенными центрами:
(x - x₁)² + (y - y₁)² = R²  ∩  (x - x₂)² + (y - y₂)² = R²

 SVG реализуется парой дуг:
path = "M x0 y0 A R R 0 0 1 x1 y1 A R R 0 0 1 x0 y0"
оэффициент прозрачности слоя: opacity = 0.35 + 0.30 * θ₇.

### 3.4. равитационный дриппинг и микрокапли (`_bold_dripping`)
Стекающие струи туши моделируются квадратичными кривыми езье:
B(t) = (1 - t)² * P₀ + 2(1 - t)t * P_ctrl + t² * P_end
где:
- P₀ = (x₀, y₀) — точка отрыва на лепестке или узле;
- P_ctrl = (x₀ + δ_wind, y₀ + 0.5 * L);
- P_end = (x₀ + Δx, y₀ + L),  L = uniform(50, 170) + 80 * drive.

Форма капель — эллипсы, вытянутые гравитацией:
ry = rx * k_stretch,  k_stretch ∈ [1.3, 2.2]

### 3.5. Текстурный шум полотна (`_paper_canvas_texture`)
Фактура строится процедурно:
- 160 волокон бумаги: длина l ∈ [2.5, 7.0] px, угол θ ∈ [0, π], opacity ∈ [0.04, 0.12].
- 350 микропор: радиус r ∈ [0.4, 0.9] px, opacity ∈ [0.05, 0.16].
