# Blues Gravity Well D2: визуальная грамматика блюза

## Цель
D2 не рисует научно-фантастическую черную дыру. Центральная воронка — метафора блюзового притяжения: неразрешенная blue note, оттянутая доля, медленный басовый вес и теплый остаток лампового перегруза.

## алитровый контракт
спользуется существующая каноническая палитра `warm_midnight` из `configs/palettes.yaml`:

- `#0E0905`: глубокая ночная пустота воронки
- `#3D2210`: внутренняя тень, дерево гитары и дымный зал
- `#8B4F1A`: аккреционная медная материя, струны и средние частоты
- `#D4923A`: тлеющий янтарный сустейн
- `#F5C97A`: редкий акцент струны или римшота

## омпозиционные ограничения
- дин центр притяжения; он не должен выглядеть как sci-fi сингулярность.
- Три мягких неравных рукава.
- Угловой разворот: не более одного оборота.
- инимум 45 процентов темного свободного пространства.
- икаких острых роковых лепестков, агрессивных вспышек или дриппинга в первой версии.
- нтарное кольцо неполное: это аккорд, намеренно оставленный без разрешения.

## узыка -> параметры

### равитационная масса
gravity = clamp01(
    0.45 * (1 - brightness)
    + 0.35 * density
    + 0.20 * (1 - spectral_skewness)
)

### тягивание в центр
inflow = clamp01(
    0.50 * tension
    + 0.30 * resonance
    + 0.20 * (1 - stability)
)

### Blue-note bend
blue_note_bend = clamp01(
    0.60 * theta_3
    + 0.25 * smoothness
    + 0.15 * (1 - symmetry_bias)
)

### Тепло лампы
tube_warmth = clamp01(
    0.45 * brightness
    + 0.30 * energy
    + 0.25 * (1 - spectral_skewness)
)

### граничения геометрии
void_radius = 54 + 34 * gravity
spiral_turns = 0.55 + 0.35 * inflow + 0.10 * theta_6

## Технические границы
D2 не меняет:
- `tools/render_d1_rock_fractal_poster.py`
- `lib/style_engine/rock_composition_v8.py`
- `scripts/render_v8_batch.py`
- `lib/style_engine/configs/visual_composition_profiles.yaml`

Сначала создается только расчётный bridge и тесты. SVG-рендерер появится после ручной оценки параметров и отдельного решения.
